# Security Policy

## Supported Versions

Security fixes are provided for the current `main` branch and the latest
published release candidate. Older snapshots are not supported.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public GitHub issue.

Instead, report it privately by emailing
[contact@dom.tech](mailto:contact@dom.tech).

Please include:

- A description of the issue.
- Steps to reproduce it.
- The affected version.

SVP is local-first tooling with no hosted network service, but responsible
disclosure is appreciated.
